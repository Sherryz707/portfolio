## Overview

At LatamRecruit, I played a pivotal role in developing and maintaining a full-stack recruitment platform that supports dynamic content management and user workflows. The core focus was on building a scalable backend system using the MERN stack with TypeScript, emphasizing clean architecture and modular design to ensure maintainability and extensibility.

The platform serves diverse user roles with distinct permissions, supports content entities like blogs and FAQs, and provides seamless admin and client-facing interfaces. The project demanded robust security measures, efficient data fetching strategies, and a smooth, cohesive user experience.

## Key Features

- **Scalable Backend Architecture**: Developed a backend system with Node.js, Express, MongoDB, and TypeScript, structured around clean architecture principles to promote modularity, testability, and separation of concerns.
- **Dynamic RESTful APIs**: Created and thoroughly tested APIs managing multiple dynamic entities, including blogs, comments, contact forms, leads, and FAQs. This modular API design allows easy future expansion and maintenance.
- **Secure Authentication & Authorization**: Implemented JWT-based authentication with role-based access control, ensuring secure workflows for admin users and general clients, protecting sensitive data and operations.
- **Frontend Integration with TanStack Query**: Leveraged TanStack Query for efficient, declarative data fetching and caching, enabling responsive and consistent data flow between the backend APIs and frontend components.
- **Reusable UI Components with React and shadcn/ui**: Extended frontend functionality by building reusable, accessible UI components using React and the shadcn/ui library, filling design gaps and maintaining a cohesive look and feel across the admin panel.
- **Email Service Integration**: Integrated Mailtrap for email testing during development and SendGrid for production transactional emails, supporting user communications such as lead notifications and contact form confirmations.

## Technologies Used

- **MERN Stack**: MongoDB, Express.js, React, Node.js — core technologies for backend and frontend development.
- **TypeScript**: For type safety and maintainable, scalable code across the stack.
- **TanStack Query**: To handle data fetching, caching, and synchronization efficiently on the frontend.
- **shadcn/ui**: For building customizable and accessible React UI components aligned with the project’s design language.
- **JWT Authentication**: Secured APIs with JSON Web Tokens for authentication and role-based authorization.
- **Mailtrap & SendGrid**: For managing email workflows during development and production stages.

## Challenges and Learnings

One major challenge was balancing backend scalability with complex user role management, ensuring that APIs remained clean and maintainable despite supporting multiple dynamic content types. Implementing secure, role-based access control demanded careful planning to avoid permission leaks or security gaps.

On the frontend, integrating TanStack Query to work smoothly with dynamic API endpoints and state changes required fine-tuning for optimal performance and user experience. Building reusable UI components that fit both admin and client interfaces also called for close collaboration with design teams to bridge any gaps effectively.

## Outcome

The platform is now a robust, scalable solution supporting a growing user base with diverse needs. The clean, modular backend architecture makes future feature expansion straightforward, while secure authentication safeguards sensitive workflows. Frontend integrations using TanStack Query and shadcn/ui deliver a responsive, consistent user experience.

This project strengthened my full-stack ownership skills — from database schema design and API development to frontend integration and UI refinement — demonstrating a comprehensive ability to deliver end-to-end solutions in a production environment.
