## Overview

For my Final Year Project (FYP), I spearheaded the development of an advanced machine learning and full-stack application focused on sign language recognition and education. The platform supports multiple sign languages including English American Sign Language (ASL), Urdu Sign Language (ASLL), and numerical signs, enabling accurate gesture detection and classification through state-of-the-art models built with FastAI.

To create an engaging and interactive learning experience, I developed immersive 3D front-end visualizations using React Three Fiber (R3F) and Three-VRM. The VRM avatars are programmatically animated in real-time based on JSON input from sign recognition models, providing dynamic and realistic sign language feedback.

A robust and scalable backend architecture was designed using Supabase with PostgreSQL to securely manage user data, track learner progress, and deliver content seamlessly. This full-stack solution integrates machine learning outputs with responsive frontend components for real-time interaction and feedback, building an accessible e-learning platform optimized for both education and usability.

## Key Features

- **Multi-Language Sign Recognition**: Developed and trained FastAI-based ML models to recognize and classify signs from multiple sign languages with high accuracy.
- **Interactive 3D Avatar Visualization**: Created real-time VRM avatar animations controlled via JSON input to visualize recognized signs, enhancing learner engagement.
- **Scalable Backend Infrastructure**: Implemented user authentication, data storage, progress tracking, and content delivery using Supabase and PostgreSQL.
- **Real-Time Frontend Integration**: Seamlessly integrated ML predictions with React frontend to provide instant feedback and interactive learning.
- **API Design & Security**: Applied best practices in RESTful API development, JWT authentication, and database schema design for a secure and maintainable system.

## Technologies Used

- **FastAI**: For developing and training deep learning models for sign recognition.
- **React Three Fiber (R3F) & Three-VRM**: For 3D avatar rendering and animation.
- **Supabase (PostgreSQL)**: Backend platform for authentication, database management, and hosting.
- **React.js & TypeScript**: For building frontend UI and integrating ML results.
- **REST APIs & JWT**: For secure communication between frontend and backend.

## Challenges and Learnings

A significant challenge was achieving real-time sign detection with low latency while maintaining high prediction accuracy across multiple sign languages. Integrating 3D animations that accurately reflected detected gestures required precise synchronization between ML outputs and VRM avatar controls.

Designing a scalable and secure backend to support dynamic user interactions and progress tracking demanded careful database schema planning and API optimization. This project deepened my understanding of combining machine learning models with rich frontend experiences and scalable backend architecture.

## Outcome

The project culminated in a fully functional e-learning platform that supports immersive, interactive sign language education with real-time feedback. It demonstrated a novel integration of AI-driven gesture recognition with 3D visualization, significantly enhancing accessibility for learners. This experience strengthened my expertise in full-stack development, machine learning engineering, and interactive web applications.
