## Overview

For my Final Year Project (FYP), I architected and delivered an end-to-end AI application that combines **deep learning-based gesture recognition** with **3D avatar-based feedback** to create an immersive, interactive sign language education platform.

The system supports English ASL, Urdu ASLL, and numerical signs, utilizing FastAI-trained CNN models for accurate, real-time sign classification. These predictions drive **live VRM avatar animations** using React Three Fiber and Three-VRM — producing a visual, embodied feedback loop ideal for learners.

A Supabase-backed backend handles authentication, content delivery, and user progress tracking — forming a robust full-stack environment where ML predictions are seamlessly integrated into the UI/UX flow. This platform bridges computer vision and real-time interactivity to push the boundaries of accessible, AI-native ed-tech.

## Key Features

- **Multilingual Gesture Recognition**: Trained convolutional neural networks (CNNs) with FastAI for accurate classification across ASL, Urdu ASL, and numeric signs.
- **Real-Time Inference Integration**: Connected ML model outputs to the frontend pipeline, enabling immediate avatar-driven visual feedback.
- **3D Avatar Control via JSON Pipelines**: Mapped ML outputs to Three-VRM avatar actions, synchronizing sign semantics with realistic animations.
- **Secure, Scalable Backend**: Designed a Supabase + PostgreSQL backend to handle user data, progression metrics, and content APIs.
- **Full-Stack AI Deployment**: Orchestrated ML model inference, database queries, and front-end rendering into a unified, real-time user experience.

## Technologies Used

- **FastAI**: Transfer learning for image classification with rapid prototyping.
- **React Three Fiber & Three-VRM**: For WebGL-powered 3D avatar animations driven by ML signals.
- **Supabase**: Backend-as-a-service with PostgreSQL, authentication, and real-time APIs.
- **React.js & TypeScript**: For building performant, component-based UIs.
- **REST APIs + JWT**: For secure model data exchange and user authentication.

## Challenges and Learnings

Integrating live ML inference into a 3D front-end pipeline required low-latency prediction serving and tight control over animation timing. Mapping gesture classifications to avatar motions meant designing a middleware layer to convert prediction tensors into semantic motion instructions.

I also encountered edge cases in model generalization across languages and sign styles, which improved my understanding of data augmentation, loss functions, and multi-class evaluation.

Architecturally, designing a system that orchestrates ML, backend, and interactive frontend components taught me to think in terms of **AI-native application flows**.

## Outcome

The final platform functions as a **real-time AI learning assistant**, offering multimodal sign feedback via accurate recognition and expressive 3D animation. It demonstrates how **AI models can be productized into user-centric applications** with meaningful educational outcomes. This experience sharpened my skills in applied ML, AI UX design, and full-stack orchestration — aligning directly with modern AI tooling and agent-based architectures.
