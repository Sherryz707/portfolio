## Overview

NutriDiaries is a blog platform developed with Next.js and powered by Sanity.io as the content management system (CMS). The project involved building a scalable and performant blog with a focus on efficient content management, customizable editing tools, and a polished UI/UX.

By leveraging Sanity.io’s flexible schema and portable text editor, I was able to optimize the data structure for faster loading and scalability, while enhancing the authoring experience with advanced rich text features. The UI/UX design was carefully crafted to be intuitive and visually engaging, boosting reader interaction and retention.

## Key Features

- **Next.js Blog Integration**: Developed a fully functional blog leveraging Next.js for server-side rendering and static site generation to maximize performance.
- **Sanity.io CMS Schema Design**: Designed and optimized the blog schema for easy content management, efficient querying, and future scalability.
- **Enhanced Portable Text Editor**: Customized Sanity.io’s editor with advanced formatting options such as highlights, improving the content creation workflow for editors.
- **End-to-End UI/UX Design**: Led the design process from initial concept sketches through final implementation, focusing on usability and aesthetic appeal.
- **Ongoing Maintenance & Iteration**: Actively managed the platform post-launch by addressing user feedback, fixing issues, and iterating on features to improve the blog experience.

## Technologies Used

- **Next.js**: Framework for building performant React applications with static and server-rendered pages.
- **Sanity.io**: Headless CMS providing a flexible and extensible content platform.
- **React & TypeScript**: For frontend development and component-based UI.
- **Portable Text Editor (Sanity.io)**: Customized rich text editor tailored for enhanced content editing.
- **CSS Modules / Tailwind CSS**: For styling and responsive design.

## Challenges and Learnings

One key challenge was extending Sanity.io’s portable text editor to support custom formatting options while maintaining a smooth editing experience. Optimizing the CMS schema to balance flexibility and performance required careful planning.

Ensuring the UI was both visually appealing and user-friendly demanded iterative testing and refinement. This project improved my skills in CMS integration, custom editor development, and fullstack design-to-deployment workflows.

## Outcome

NutriDiaries successfully launched as a fast, scalable blog platform that empowered content creators with a rich editing experience and readers with a seamless browsing interface. The ongoing maintenance phase allowed continuous enhancements, ensuring the platform meets evolving user needs.
