## Overview

At ScryptHub, I played a central role in developing and maintaining a scalable full-stack application with a strong emphasis on backend architecture. The core focus was on building secure, RESTful APIs for managing user roles, teachers, and students, while integrating with services like WhatsApp and SendGrid for communication. The solution prioritized security, clean architecture, and performance — enabling a seamless admin experience for educational clients.

## Key Features

- **End-to-End Role Management**: Designed and implemented CRUD APIs to manage roles, students, and teachers, including detailed access logic and role-based permission handling.
- **Secure Authentication and Authorization**: Set up JWT-based authentication workflows with clear role separation and access control, ensuring data confidentiality.
- **Express.js Modular Architecture**: Built backend services using a clean architecture pattern — separating concerns across routes, controllers, services, and middleware for maintainability.
- **Error Handling Layer**: Introduced centralized error controllers and response formatting to streamline debugging and provide consistent API feedback.
- **External Integrations**: Integrated WhatsApp APIs and SendGrid to enable seamless communication with students and admins — including transactional notifications and alerts.
- **Postman-Tested Endpoints**: Each route was rigorously tested with Postman collections and documentation to ensure production readiness and ease of handoff.

## Technologies Used

- **Node.js & Express.js**: For backend logic, routing, and RESTful API structure.
- **MongoDB**: As the primary NoSQL database, enabling dynamic document modeling for user roles.
- **TypeScript**: To ensure type safety and reduce runtime bugs across backend services.
- **React & Next.js**: For supporting front-end views and integrating dynamic API routes where needed.
- **SendGrid & WhatsApp API**: For handling outbound communication flows to users.
- **JWT**: For securing authentication flows and enforcing role-based access control.
- **Postman**: For API testing, validation, and documentation.

## Challenges and Learnings

Crafting a clean, modular backend architecture from scratch required careful planning — particularly in managing separation of concerns and layering middleware without creating tight coupling. Building reusable, testable modules helped streamline API expansion. Managing external API integrations like WhatsApp also introduced edge cases around network reliability and authentication token refresh, which were resolved through retry logic and modular service wrappers.

## Outcome

The new backend system enabled ScryptHub to onboard educational partners more efficiently, offering a secure and robust interface for managing users and triggering communications. The project laid the foundation for future feature expansion and earned praise from the product team for its clear structure and maintainability. It also significantly reduced manual communication by automating role-based alerts.
