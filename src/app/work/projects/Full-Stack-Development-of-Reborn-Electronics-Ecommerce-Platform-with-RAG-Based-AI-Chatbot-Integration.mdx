## Overview

I led the full stack development of Reborn Electronics' ecommerce platform, building a responsive and scalable web application that offers a seamless shopping experience. Utilizing Next.js for the frontend and Saleor as a headless ecommerce backend with GraphQL APIs and URQL, the platform handles efficient data fetching and state management.

To enhance customer support and engagement, I integrated a Retrieval-Augmented Generation (RAG) based chatbot using Ollama and LangChain, powered by vector embeddings, enabling users to receive real-time, context-aware assistance directly on the platform.

## Key Features

- **Next.js & Saleor Integration**: Developed a performant React frontend tightly integrated with Saleor’s GraphQL backend using URQL for optimized data management.
- **Core Ecommerce Pages**: Implemented responsive catalog and product detail pages with pagination, filtering, and secure checkout workflows.
- **RAG-Based AI Chatbot**: Integrated an intelligent chatbot leveraging Ollama vector embeddings and LangChain for context-aware, retrieval-augmented responses to user queries.
- **Design Collaboration**: Worked closely with UI/UX designers to implement pixel-perfect interfaces from Figma designs using Headless UI components.
- **Secure Payment Integration**: Engineered seamless payment flows via JazzCash with robust security measures and data privacy safeguards.

## Technologies Used

- **Next.js**: For building scalable and performant frontend interfaces.
- **Saleor**: Headless ecommerce backend with GraphQL API.
- **URQL**: GraphQL client for efficient data fetching and caching.
- **Headless UI**: Accessible, customizable React UI components.
- **JazzCash API**: Secure payment gateway integration.
- **Ollama + LangChain**: For building the RAG-based AI chatbot with vector embeddings.

## Challenges and Learnings

Integrating the RAG chatbot within the ecommerce flow required careful orchestration of asynchronous API calls and seamless UI integration to maintain smooth user interactions. Managing payment security alongside real-time chatbot responses called for robust state and error handling mechanisms.

Implementing dynamic product pages with filtering and pagination alongside chatbot support tested my ability to manage complex frontend state and backend data efficiently while preserving a responsive user experience.

## Outcome

The ecommerce platform successfully delivers a secure, scalable shopping experience enhanced with an AI-powered chatbot, providing instant, context-aware customer assistance. This integration elevated the platform’s interactivity and user satisfaction, supporting business goals and user retention.

This project strengthened my full-stack development skills, particularly in integrating AI-driven tools into traditional ecommerce workflows, demonstrating a blend of frontend/backend expertise with emerging AI capabilities.
