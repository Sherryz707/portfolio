## Overview

For my Final Year Project (FYP), I developed an AI-powered **e-learning platform** designed to teach sign language through real-time gesture recognition and interactive 3D avatars. The system supports English ASL, Urdu ASL, and numerical signs, using FastAI with ResNet34 to classify signs in real time. These predictions drive **VRM avatars**, animated using Blender and rendered with React Three Fiber and Three-VRM, to provide visual feedback for learners.

The platform includes four interactive quiz types:

- **Coloring the Alphabet**
- **3D Teacher with Live Camera Checking**
- **Card Selection Quiz**
- **Sleepy Letter** (requiring three correct signs to "wake" a letter)

A Supabase backend handles authentication, content delivery, and progress tracking, offering a seamless, scalable experience that blends computer vision with immersive, web-based learning.

## Key Features

- **Multilingual Sign Recognition**: Trained ResNet34 models with FastAI for accurate real-time classification of ASL, Urdu ASL, and numeric signs.
- **Interactive Quizzes**:
  - **Coloring the Alphabet**: Practice signing by coloring letters.
  - **3D Teacher with Live Checking**: Real-time sign verification using a webcam.
  - **Card Selection Quiz**: Choose the correct sign from displayed cards.
  - **Sleepy Letter**: Sign correctly three times to "wake" a letter.
- **3D Avatar Feedback**: VRM avatars, animated in Blender, respond to ML predictions for intuitive visual cues.
- **Scalable Backend**: Supabase with PostgreSQL manages user data, quiz progress, and content APIs.
- **Full-Stack Integration**: Unified ML inference, backend APIs, and 3D frontend for a cohesive learning platform.

## Technologies Used

- **FastAI & ResNet34**: For transfer learning and sign classification model development.
- **Blender**: For animating VRM avatars with precise, non-AI-driven motion design.
- **React Three Fiber & Three-VRM**: For rendering and controlling 3D avatars in the browser.
- **Mixamo**: Used for supplementary animation assets where applicable.
- **Supabase**: Provided PostgreSQL, authentication, and real-time APIs.
- **React.js & TypeScript**: Built performant, component-based user interfaces.
- **Gradio & Hugging Face Spaces**: Hosted ML models for API-driven inference.
- **REST APIs + JWT**: Enabled secure data exchange and user authentication.

## Challenges and Learnings

Deploying large ResNet34 models to Hugging Face Spaces via Gradio was challenging due to resource constraints and API latency. Animating VRM avatars with Three-VRM, a niche library, required custom middleware to map ML predictions to Blender-crafted animations, ensuring smooth and accurate movements.

Generalizing the model across diverse sign languages improved my skills in data augmentation and multi-class classification. Orchestrating ML, backend, and 3D frontend components taught me to design **low-latency, AI-native systems** tailored for interactive education.

## Outcome

The final product is a fully functional **e-learning platform** that combines real-time sign language recognition with immersive 3D visuals and interactive quizzes. It demonstrates how AI, animation, and full-stack engineering can converge to build meaningful educational experiences. This project sharpened my skills in applied ML, 3D animation pipelines, and cross-stack system design.
